# asrepoya/nova (Nova 4 + Laravel 13 compatibility fork)

Private fork of Laravel Nova 4.32.14 with Composer and bootstrap patches for Laravel 13.

- Requires a **valid Laravel Nova license**
- Keeps `Laravel\Nova\` APIs for existing resources/tools
- Replaces Composer package name `laravel/nova` via `replace`

See [COMPATIBILITY.md](./COMPATIBILITY.md) for change log, install, and limitations.
